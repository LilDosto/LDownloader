3. KAYNAK KOD DEĞİŞİKLİKLERİ (ytdlp_gui.pyw)
================================================================================

3.1 — _APP_DIR Güncellenmesi (Satır 34)
----------------------------------------

SORUN:
  Orijinal kodda kaynak dosyaların yolu şu şekilde bulunuyordu:

    _APP_DIR = os.path.dirname(os.path.abspath(__file__))

  PyInstaller ile --onefile modunda paketlendiğinde, __file__ geçici bir
  dizini gösterir ve logo.png, logo.ico gibi dosyalar bulunamaz.

ÇÖZÜM:
  İki ayrı fonksiyon eklendi:

  a) _get_app_dir() — Gömülü kaynaklar için (logo.png, logo.ico):
     - PyInstaller ile çalışıyorsa: sys._MEIPASS (geçici çıkarma dizini)
     - Normal Python ile çalışıyorsa: __file__ dizini

  b) _get_exe_dir() — Kullanıcı dosyaları için (cookies.txt):
     - PyInstaller ile çalışıyorsa: sys.executable dizini (exe'nin konumu)
     - Normal Python ile çalışıyorsa: __file__ dizini

  Eklenen kod:

    def _get_app_dir():
        """PyInstaller ile paketlendiğinde kaynak dosyaları bulmak için."""
        if getattr(sys, 'frozen', False):
            return sys._MEIPASS
        return os.path.dirname(os.path.abspath(__file__))

    _APP_DIR = _get_app_dir()

    def _get_exe_dir():
        """EXE'nin bulunduğu dizin (cookies.txt gibi kullanıcı dosyaları için)."""
        if getattr(sys, 'frozen', False):
            return os.path.dirname(sys.executable)
        return os.path.dirname(os.path.abspath(__file__))

    _EXE_DIR = _get_exe_dir()


3.2 — cookies.txt Yolunun Güncellenmesi (2 yer)
-------------------------------------------------

SORUN:
  cookies.txt hem tekil indirme hem playlist indirme fonksiyonlarında
  şu şekilde aranıyordu:

    cookies_file = os.path.join(
        os.path.dirname(os.path.abspath(__file__)), "cookies.txt"
    )

  EXE olarak çalıştırıldığında bu yol geçici dizini gösterir ve
  cookies.txt bulunamaz.

ÇÖZÜM:
  Her iki yerde de _EXE_DIR kullanıldı:

    cookies_file = os.path.join(_EXE_DIR, "cookies.txt")

  Değişen fonksiyonlar:
    - _start_single()   (tekil indirme)
    - _start_playlist() (playlist indirme)

  Bu sayede cookies.txt, exe dosyasının yanına konulduğunda otomatik
  olarak bulunur.

4. PyInstaller İLE EXE OLUŞTURMA
================================================================================

Kullanılan komut:

  pyinstaller --noconfirm --onefile --windowed --icon="logo.ico"
    --name="ytdlp_indirici"
    --add-data="logo.png;."
    --add-data="logo.ico;."
    --add-data="logo_16.png;."
    --add-data="logo_32.png;."
    --add-data="logo_48.png;."
    --add-data="logo_64.png;."
    ytdlp_gui.pyw

Parametrelerin açıklamaları:

  --noconfirm       : Önceki build dosyalarını sormadan üzerine yaz
  --onefile          : Tek bir .exe dosyası oluştur (tüm bağımlılıklar içinde)
  --windowed         : Konsol penceresi açılmasın (GUI uygulaması)
  --icon="logo.ico"  : EXE dosyasının ikonu olarak logo.ico kullan
  --name="ytdlp_indirici" : Çıktı dosyasının adı
  --add-data="X;."   : X dosyasını exe içine göm (çalıştırıldığında çıkarılır)
